# Welcome to Folio

A local Markdown workspace for people and Agents.

## Start with your documents

Open a Markdown file with **⌘ O**, or choose a project folder from the project home. Your files stay in their original folders.

- **Writing:** edit with live formatting.
- **Source:** see and edit the Markdown directly.
- **Reading:** focus on the rendered document.

## Work together

Folio watches for changes made by other tools. Unsaved edits remain available for review. Agent proposals require your confirmation and preserve a version backup.

## Technical writing

Inline math: $E=mc^2$.

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

| Feature | Where to start |
