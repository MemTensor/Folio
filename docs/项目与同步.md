# 项目与同步

## 以项目开始

首页展示最多 6 个常用／最近项目和 8 篇最近文档。点星标可置顶项目，点击最近文档可直接继续阅读。其余项目从“添加项目”中搜索；也可选择“打开文件夹”添加。文件保持在原目录，首页不会搬动文档。标题栏的书本按钮可随时返回首页；“启动时显示项目首页”可在“设置 → 项目与同步”中关闭。标签恢复另由“设置 → 通用”管理。

进入项目后，左侧默认显示文档列表：按名称筛选，按最近修改或名称排序，并显示文档所在目录。同名文件可通过路径区分。首批显示 100 篇，点击“加载更多”继续查看。备份、归档、代码镜像和临时输出等目录默认略过，可开启“包含备份与镜像”查看；依赖、隐藏目录和符号链接始终跳过。

列表在独立后台线程读取文件元信息，不读取正文；缓存最多保留 24 个项目视图、合计 12 MB，单次最多检查 10,000 个目录项、收录 2,000 篇文档，并有时间上限。达到范围上限时会提示，可打开更具体的子文件夹。列表显示期间只监听少量已展示文档的父目录，已知文件变化按项更新；没有定时轮询，深层新文件可手动刷新。

“文件夹”视图保留原始目录结构，按需展开下一层，不会自动打开任意第一篇文档。排序逐层生效，文件夹显示在文件前。列表与文件夹分别记住排序方式。大型或慢目录可取消和重试，收起后按需释放监听。

## Codex 与 Claude Code 项目

“发现 Agent 项目”默认关闭，可在首次引导或设置中开启。Folio 只读取本机明确记录的项目路径：Codex 的项目配置与桌面项目记录、Claude Code 的项目记录。不会读取会话正文，也不会遍历整个个人目录。

发现结果使用缓存，最多展示 200 个项目，集中放在“添加项目”面板中；临时任务默认隐藏，可勾选包含，路径不可用的记录不显示。首页只保留已打开或置顶的可用项目。后台只监听项目记录文件的变化，合并短时间内的多次通知，不定时轮询；发现面板的刷新按钮可重新读取记录。只有实际打开项目后，Folio 才加载其文档和文件监听。

## iCloud Drive

先在 macOS 系统设置中启用 iCloud Drive；系统配置方法见 [Apple 支持](https://support.apple.com/en-us/118443)。Folio 不需要你的 Apple 账号密码。

在首次引导或“设置 → 项目与同步”中开启“iCloud 文档同步”，再选中要同步的项目。默认没有选中项目，不会自动上传整个文档库。

同步范围：

- Markdown 文件（`.md`、`.markdown`、`.mdown`）。
- Markdown 链接或图片语法引用的本地图片、PDF、Office 文档及常用媒体附件。
- 单文件严格小于 100 MB。隐藏文件、依赖、构建产物、凭据文件、符号链接和项目外引用会跳过。

Folio 在 iCloud Drive 的 `Folio` 文件夹中维护按项目分开的副本。修改先写入本机 iCloud Drive 文件夹，实际上传和跨设备下载由 macOS 完成；“上次同步”不代表系统已完成云端传输。

单边修改会同步到另一端；两边都改变时，首页显示冲突，可选择保留本地或采用 iCloud 版本。选择前再次核对版本，后续修改不会被旧选择覆盖。删除不会传播到另一端。关闭同步保留现有文件。

### 在另一台 Mac 上连接

先在该 Mac 打开对应的本地项目，开启 iCloud 同步并选中它，再从该项目下方的选项连接已有 iCloud 项目。Folio 不按同名文件夹自动关联，以免将两个不同项目混在一起。“独立同步此项目”可解除连接，保留已有文件。

### 资源限制与离线

后台不轮询，只处理所选项目和已知云端目录的文件事件；短时间多次修改会合并处理。每轮最多扫描 10,000 个目录项、2,000 个文档／附件、16 层目录，并限制读取总量与运行时间。云端最多监听 128 个已知目录；深层新增目录可通过“立即同步”补充。达到限制时会提示，建议选择更具体的项目文件夹。

大于或等于 2 MB 的 Markdown 仍可同步正文，但不会在后台解析它的附件引用。代码、远程网络图片和内嵌 HTML 中的任意文件链接不会被自动扩展为同步范围。

iCloud 不可用、文件尚未下载到本机、文件正在改变或状态异常时，保留原文件并跳过本轮处理。系统恢复后可点击“立即同步”。替换前的恢复副本保存在本机应用数据目录，最多保留 64 份、合计 512 MB；这不替代项目的 Git 或长期备份。

## 大文档

文档超过 256,000 字符、5,000 行，或单行超过 20,000 字符时，使用轻量源码模式，暂停实时预览、大纲和精确字数统计。原文、编辑、保存和冲突保护继续可用。

## 语言

首次引导和“设置 → 项目与同步”中可选择简体中文或 English，界面与原生菜单随即切换。语言选择不翻译或修改文档正文、公式、图表源码、文件名和发布说明。
