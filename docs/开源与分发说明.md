# 源码与分发状态

## 仓库

Folio 的源码仓库为 **MemTensor/Folio**，当前是私有仓库。项目使用 `UNLICENSED` 标记，尚未授予开源许可，也没有添加开源 `LICENSE`。协作者按获准的访问范围参与开发。

可分发的源码、示例、skill 和 plugin 位于仓库中。真实文档、账号凭据、草稿、对话、签名证书及本机启动配置不属于源码。

## 安装包

安装包发布到 [MemTensor/Folio Releases](https://github.com/MemTensor/Folio/releases)，使用该仓库的确定提交重新构建，通过完整检查，并在上传后回读摘要与大小。v0.5.0-beta.14 同时作为旧版迁移更新，升级后使用新仓库检查更新。

目前支持 macOS Apple Silicon ZIP。本地构建采用本地签名，尚未配置 Developer ID 和 Apple 公证。检查与发布流程见 [开发指南](开发指南.md)，安装和更新见 [更新说明](更新说明.md)。

## 后续公开分发

公开前需要另行确定项目许可证、确认所含代码和素材的授权、完成分发签名与公证，并核对实际安装包的下载、启动、CLI、导出和更新行为。公开仓库或安装包的操作不包含在当前私有交付中。

依赖授权文本随构建收集；[第三方组件说明](../THIRD_PARTY_NOTICES.md) 与生成的许可证清单应一起复核。用户数据的保存与传输范围见 [架构与数据边界](架构与数据边界.md)。
