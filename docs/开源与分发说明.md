## 分发时保留什么

Apache-2.0 允许使用、修改、商用和再分发，也允许闭源衍生。分发时需按许可证第 4 条提供许可证副本、保留相关声明，并标记修改过的文件；衍生分发还需保留适用的 NOTICE 署名信息。

[NOTICE](../NOTICE) 包含项目名称、版权主体、作者和来源。可按第 4 条将适用声明放在随附 NOTICE、源码／文档或适当的声明界面中；不要求每个产品首页都展示作者，也不在 NOTICE 中增加许可证之外的限制。署名不表示 MemTensor 或作者为衍生产品背书。

[AUTHORS.md](../AUTHORS.md) 记录作者身份，[CITATION.cff](../CITATION.cff) 提供推荐引用格式。引用时建议附实际版本或提交；引用建议不等于额外许可条件。

## 仓库与发行包

仓库仍为私有；许可证不改变 GitHub 访问权限。获得代码的人可按 Apache-2.0 的条件使用和再分发。

授权在加入 LICENSE 与 NOTICE 的源码版本中明确给出。既有 v0.5.0-beta.22 及更早安装包保持原样；后续从本源码构建的应用、插件和独立 skill 均应随附许可与署名文件。

安装包发布到 [MemTensor/Folio Releases](https://github.com/MemTensor/Folio/releases)，从确定提交重新构建，并核对上传资产的摘要与大小。目前支持 macOS Apple Silicon；Developer ID 签名和 Apple 公证尚未配置。流程见 [开发指南](开发指南.md) 和 [更新说明](更新说明.md)。

构建会收集依赖的授权文本。包内同时保留 Folio 自身的 LICENSE、NOTICE、作者与引用文件，以及第三方组件说明。使用新的第三方代码、字体、图标或其他素材前，应核实其授权条件。

公开仓库、改变许可证或替换已发布资产均需另行授权。真实文档、凭据、草稿、对话与签名证书不属于源码分发范围。数据边界见 [架构与数据边界](架构与数据边界.md)。
