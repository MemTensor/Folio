# 更新 Folio

Folio 从 [MemTensor/Folio Releases](https://github.com/MemTensor/Folio/releases) 获取版本说明和安装包。更新保留 Markdown 原文、文档状态及恢复草稿。

## 检查、下载与安装

1. 打开“Folio → 检查更新”或“设置 → 关于与更新”，也可在命令面板中选择“检查更新”。
2. 有更高版本时，查看版本说明并点击“下载更新”。下载期间可以继续写作，也可以取消下载。
3. 下载完成并通过校验后，点击“保留草稿并重启更新”。
4. Folio 保留未保存内容和待审阅修改，再退出并替换应用。新版启动后恢复当前标签，继续处理文档；更新重启不受“启动时恢复标签”的普通启动偏好影响。

更新只更换应用，Markdown 原文件和本机文档状态继续保留。安装前若草稿无法保存，或文档在准备期间发生变化，会暂停更新并返回编辑。

正在使用表格、公式或图表编辑器时，先完成或关闭编辑器。正在输入法组字、保存、恢复历史等操作时，稍后再试。文件已从磁盘删除时，先另存或重新创建，再更新。

## 下载与访问

当前发布仓库公开，检查与下载优先使用匿名 HTTPS，无需安装或登录 GitHub CLI。本机过期登录和无效 Token 不参与正常的公开更新请求。

如果使用私有分发或遇到访问限制，拥有对应权限的账号可通过本机 GitHub CLI 登录：

```bash
gh auth login
```

没有 `gh` 时，先安装 [GitHub CLI](https://cli.github.com/)。Folio 在主进程中复用其登录状态，无需把 Token 填进应用、文档或聊天。登录成功仍需具备发布仓库的访问权限。

网络不可用、登录失效、权限不足或服务限流时，应用会说明检查失败；稍后可重试，也可打开发布页面手动下载。无法访问服务不代表已经是最新版。

## 更新渠道

正式版本仅接收更高的正式版本。预发布版本可以接收更高的预发布版本或正式版本。版本按照版本号比较，不依据发布日期或列表顺序；相同版本和较低版本不会作为更新安装。

本地构建可能比 GitHub 上的版本更新。此时没有可下载的新版本属于正常情况。未发布完成、没有匹配架构安装包或缺少校验文件的版本不会被提供为可安装更新。

## 完整性与恢复

下载完成后，Folio 核对安装包的 SHA-256、文件大小、应用标识、版本及架构。解包与替换之前还会检查包内路径和文件结构。失败的校验不会进入安装。

应用需位于有写入权限的本机应用目录。请先把 `Folio.app` 放入应用程序文件夹；从只读磁盘映像或受限临时位置运行时，先完成常规安装。

替换应用采用同一磁盘卷上的原子交换并保留旧包。交换或启动失败时恢复旧版；新版未确认启动且已退出时也会尝试恢复。若新版仍在运行，保留备份而不打断文档操作。若应用提示需要处理恢复结果，请保留旧包和更新记录，按提示核对后再试。

当前发行包尚未进行 Apple Developer ID 签名和公证。下载校验、固定发布来源与旧包备份用于保护完整性和恢复能力，不能替代 Apple 对开发者身份的认证。

## 较早版本

v0.5.0-beta.13 及更早版本曾使用旧仓库。安装 v0.5.0-beta.14 或更新版本后，后续检查使用 MemTensor/Folio。如果旧版无法检查更新，可从当前发布页面下载并手动替换应用。
