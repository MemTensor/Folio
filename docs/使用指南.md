# Folio 使用指南

本指南对应 v0.5.0-beta.13；版本差异见 [更新记录](../CHANGELOG.md)。

## 项目首页与首次引导

首次打开时，可快速了解阅读、项目管理与 Agent 协作。引导可以跳过，也可在写作设置中重新查看。项目首页可显示已打开的文件夹，以及显式开启发现后的 Codex／Claude Code 项目。标题栏的书本按钮可随时返回首页；文件侧栏右上角可切换名称或修改时间排序。英语和 iCloud 设置详见 [项目与同步](项目与同步.md)。

## 打开和管理文档

Folio 直接打开 Markdown 文件与项目文件夹。使用 **⌘ O** 打开文件，**⌘ ⇧ O** 打开文件夹，**⌘ P** 快速定位当前项目中的文档。

点击左侧项目名称，可查看最近文档并跨项目搜索文件名和正文。不同项目的文档可以同时保留在标签栏，同名文档会显示项目名称。重启时会尝试恢复最近 30 个标签及可用草稿。

不再需要某个项目时，可在文档库中移除它。这会停止收录该项目并移除搜索数据，原文档仍保留在磁盘上。项目中有未保存或待审阅内容时，先处理这些文档再移除。请添加具体项目文件夹，避免将系统根目录或整个用户目录作为项目。

在文件树右键点击文档，可以重命名、复制路径、在 Finder 中显示或移入回收站。

## 阅读和写作

- **写作**：当前段落可直接编辑，其他内容保持排版。
- **源码**：查看完整 Markdown，使用行号、代码高亮和查找替换。
- **阅读**：以排版后的正文阅读文档。

设置采用左侧分类、右侧内容布局。外观、写作、阅读、项目与同步、Agent、AI 记忆、关于与更新分别管理相关选项。

在“设置 → 阅读 → 默认复制格式”中选择 Markdown 源码或带格式文本，默认使用带格式文本。此选项影响阅读模式的 ⌘C；右键菜单同时提供“复制 Markdown 源码”和“复制带格式文本”。完整段落复制保留原 Markdown，局部选区保留加粗、链接等语法；带格式复制保留标题、列表、表格和已渲染公式。

外观中可调整主题、字体、字号和正文宽度；写作中可调整专注模式、打字机模式和自动保存。已排版的段落和代码块可直接拖选并复制文字；单击进入源码编辑。点击文字设置起点后，按住 Shift 再点击终点，可正向或反向选择多个段落。标题的 Markdown 标记在写作时隐藏，切换源码模式仍可查看和编辑。预览出错时可切换到源码继续处理原文。

## 右键菜单

- **正文**：复制、全选、打开 Agent、复制文档路径；进入文字编辑后，可剪切、粘贴、设置格式，以及插入公式、图表、表格与代码块。阅读模式全选只选正文。
- **排版后的公式、图表与表格**：在写作模式下右键，打开对应编辑器。
- **文档列表**：打开、重命名、复制完整或相对路径、在 Finder 中显示、移入回收站。
- **标签**：保存、复制路径、在 Finder 中显示，以及关闭当前、其他、右侧或全部标签。关闭前保留恢复草稿。
- **输入框**：原生剪切、复制、粘贴、粘贴为纯文本与全选。

菜单打开后文档发生变化，格式命令不会作用于过期选区；重新打开菜单即可继续。

## 公式、图和表

**公式**支持行内 `$...$`、`\(...\)` 与块级 `$$...$$`、`\[...\]` LaTeX，包括矩阵、多行对齐、分段函数、显式编号、局部宏和化学式。点击公式进入编辑器，可同时查看源码与预览；编辑已有块级公式时保留原来的分隔符。

**图表**使用 Mermaid 源码，可选择模板并预览流程图、时序图等。

**图片**可以从本机插入、粘贴或拖入。Folio 将图片复制到文档旁的 `assets/` 并插入相对路径。移动项目时，请连同资源目录一起移动。网络图片默认关闭，可在“设置 → 阅读”或图片占位区启用。

**表格**支持可视化编辑、增删行列、列对齐，以及从电子表格粘贴多行多列内容。公式和格式仍保留在 Markdown 源码中。

可打开 [公式、图与表样例](../examples/公式、图与表.md)查看完整示例。

## 与外部工具共同编辑

让 Folio 与 Claude Code、Codex 或其他编辑器打开同一份文件即可协作。

- 没有本地修改时，外部更新会自动同步，并保留差异供审阅。
- 存在本地草稿时，Folio 保留双方内容，等待你合并或选择版本。
- 开启“所有外部修改先审阅”，可以让更新始终先经过审阅。
- 外部工具删除文件时，编辑区内容仍保留，可审阅后决定恢复文件或关闭标签。
- 修改范围过大时，Folio 显示完整双方版本，由你选择保留内容或手动合并。
- 历史版本和恢复草稿可用于找回先前内容。

命令面板中的“复制协作上下文”可复制当前文件路径和选区，方便交给 Agent。

## 保存与恢复

自动保存默认在停止输入 1.5 秒后触发；有待审阅修改时暂停。恢复历史版本会先保留当前编辑内容，再将所选版本放入编辑区，等待你确认保存。这只暂停该文档的自动保存，其他文档继续按设置工作。关闭带有未保存内容的窗口时，可选择保存或保留恢复草稿。

草稿、历史快照及本地搜索索引位于 `~/Library/Application Support/Folio/`。每个文件通常最多保留 80 个不同内容的快照，历史记录默认总配额为 256 MiB。超过配额时优先清理较旧的普通版本；必要恢复副本仍会保留，超额时会提示。索引可从原文件重建；历史快照覆盖的是 Folio 已记录的版本，不能代替完整备份。

当前支持 UTF-8 文本，包括 BOM、LF 和 CRLF；单文件上限为 16 MB。混合换行文件在修改范围过大、无法及时保留原格式时会停止写入，原文件与草稿保持不变；可分段保存，或使用其他工具将换行格式统一后重新读取。版本检查可以发现大多数同时写入，但普通文件系统无法保证任意第三方工具竞争写入时绝对无损。重要文档仍建议使用版本管理或备份。

## 导出

从文件菜单选择导出格式：

| 格式 | 支持情况 |
| --- | --- |
| PDF | 保留矢量公式和图表，嵌入图片 |
| HTML | 生成可独立阅读的文件，嵌入本地资源 |
| Word | 需要本机安装 Pandoc；常见公式保持可编辑，特殊公式和图表使用 SVG |

Word 中的 SVG 插图需要支持 SVG 的 Word 版本。不同格式的复杂排版可能有所差异。

## 发布到钉钉

保存文档后，从“发布或同步到钉钉”入口创建或更新在线文档。正文和表格可在线编辑，公式和 Mermaid 图表以图片呈现。出现发布结果不明确或云端独立修改时，在“同步问题处理”中核对内容并选择后续操作。详细准备步骤、恢复方式与限制见 [钉钉集成说明](钉钉集成说明.md)。

## Agent 文档助手

文档右上角的 **Agent** 可连接本机 Codex 与 ChatGPT 订阅，提问、修改和审阅当前文档。所选文字与同项目参考文档均可作为上下文。完整操作见 [Agent 文档助手](Agent文档助手.md)。

## 可选项目记忆

在“设置 → AI 记忆”中配置 MemOS API Key，并为当前项目选择或创建知识库。Agent 通过已启用的 Folio skill 使用它。基础文档功能不依赖这项配置。

更多信息见 [Agent 接入指南](../integrations/README.md)。

## 更新应用

从“设置 → 关于与更新”或命令面板中的“检查更新”打开版本面板：先查看说明并下载，下载期间可继续写作；准备好后点击“保留草稿并重启更新”。未保存内容与待审阅修改会保留为恢复草稿，更新后继续处理。

正在编辑表格、公式或图表时，先应用或关闭编辑器。磁盘上已删除的文件需先另存或重新创建。若准备更新期间文件发生变化，Folio 会暂停安装，供你检查后重试。

私有测试版需要有仓库访问权限的 GitHub 账号。Folio 可使用本机 `gh` 登录，缺少配置时会提示操作方法。当前安装包未进行 Developer ID 签名与公证；完整性校验和旧包备份不等同于 Apple 的开发者身份认证。详见 [更新说明](更新说明.md)。
