# Windows beta.25 验证记录

此页供开发者定位 Windows 兼容性问题。面向使用者的下载与安装说明见 [最新发布](https://github.com/MemTensor/Folio/releases/latest)。

- 环境：Windows x64，Node.js 24.22.1。
- `npm run check` 中的测试汇总：504 项，431 通过，69 失败，4 跳过。全量检查未通过。
- 失败涉及 macOS 专用命令及 helper 用例、Windows 符号链接权限、路径与权限断言、同步、清理和时序用例。尚未确认这些失败都仅限于测试环境，不能据此宣称 Windows 全功能通过。
- 分别运行的格式、生产构建、应用打包与包内容检查通过。包内容覆盖 workers、文档目录、SQLite 搜索、Agent 修改建议、随包 CLI、LICENSE 与 NOTICE。
- 中英文桌面场景、标题、编辑回归、退出，以及使用生成文档和隔离应用状态的已打包应用启动、阅读、编辑、本地图片与保存检查通过。
- 安装程序归档完整性检查通过。未完成真实系统安装与卸载验证。
- 未调用真实模型或钉钉账号；iCloud、代码签名及完整跨平台兼容性未纳入已通过范围。

本次下载页同时收录 macOS beta.24 的既有安装包，内容与原发布一致；本页的 Windows 检查结果不代表重新验证了 macOS。
