# Agent 文档助手

在文档右上角点击 **Agent**，或按 **⌘ J**，即可展开文档助手。面板可以随时关闭，文档的阅读、编辑和保存继续独立使用。

## 选择接入方式

点击面板标题旁的 ChatGPT／兼容 API，或进入“写作设置 → Agent 设置”。接入方式和断开操作集中在这里；面板只显示连接状态。

### ChatGPT 订阅

先在本机安装 [Codex CLI](https://learn.chatgpt.com/docs/cli)，再在 Folio 面板中点击“连接 Codex”。首次连接会打开官方登录页面；使用包含 Codex 权限的 ChatGPT 账号完成授权后，面板自动连接。之后重新打开面板或重启 Folio，会自动恢复已保存的登录和所选模型；主动点击“断开连接”后，自动恢复暂停，直到再次连接。

这项接入使用本机 Codex 的官方 app-server 协议，按账号的可用模型和使用额度运行。Folio 使用独立的 Codex 配置与凭据目录，不更改你在终端或其他应用中的 Codex 登录、插件和设置，也不需要填写 API Key。模型列表不保证每一次请求都有额度；额度耗尽或授权失效时，面板会提示。

当前是本地测试版接入。官方对本地／开源应用和收费／远程托管服务有不同的接入要求，详见 [官方认证说明](https://learn.chatgpt.com/docs/app-server#auth-endpoints)。

### OpenAI 兼容 API

选择“兼容 API”，填写服务的 API 基础地址、API Key 和模型名称，再点击“保存并连接”。基础地址通常包含 `/v1`，例如 `https://api.openai.com/v1`；本机服务支持 HTTP，未启用鉴权时 Key 可以留空。

API Key 通过系统安全存储加密，界面只显示是否已保存。留空可保留同一服务的现有 Key；更换远程服务地址时需要填写对应的 Key。保存后可点击“检测服务”，获取模型列表；不提供模型列表的服务也可手动填写模型名称。

本版支持 [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) 的文本请求和流式回复。模型请求使用所配置服务的 API 额度，独立于 ChatGPT 订阅。API 接入可以在没有安装 Codex CLI 的情况下使用，也保留相同的选区范围、修改审阅和撤销保护。

## 提问或修改

直接输入问题或修改要求，无需切换模式。Agent 根据你的指令理解、解释和检查，或生成可审阅的修改建议；同一个请求也可以同时包含说明和修改。提问本身不会应用任何修改。

在输入框下方选择模型和思考强度。ChatGPT 接入只列出当前模型返回的可用档位；“默认强度”沿用模型默认值。选择按接入方式与模型分别保存在本机。兼容 API 通过 `reasoning_effort` 传递所选强度，服务不支持时可改回默认。

默认上下文是当前文档的编辑内容，包括尚未保存的草稿。选择文字后可点击“选区”，此时只把选中的 Markdown 发送给模型。进入面板前已选中文字时，会自动带入选区。选区期间原文发生变化，需要重新选择或切回当前文档。

点击加号可添加当前项目中的参考文档，最多三份。参考文档供模型阅读，修改建议只作用于当前文档。文件路径、正文和参考文档不会自动跨项目收集。

使用整篇文档提问或修改时，Agent 可按需查找当前项目的 Markdown／文本文件，并读取相关段落。回复旁的“参考了 N 份项目文档”可展开来源与行号，点击文件名可打开原文。选区请求只看选中的内容和你显式添加的参考文档。

自动读取排除隐藏目录、依赖、备份、归档和项目外路径；单文件最多读取 512 KiB，每段最多约 1.2 万字符，每次请求最多六次查找／读取，总参考内容约 3.6 万字符。读取不修改文件，也不触发新的后台扫描或全盘搜索。

参考文档使用已保存的版本。当前版本每次支持约 24 万字符的文档与参考内容，超出时会提示缩小范围。

按 Enter 发送，Shift Enter 换行。回复期间可以停止。每轮处理按思考强度设置等待时间，有实际进度时续期；多轮读取和修正不共用固定三分钟倒计时，整个任务最多运行三十分钟。主动停止、等待超时和退出中断分别显示，原指令保留，可在当前文档中重试。完成首次连接后，后台会话保持到应用退出；关闭、收起和切换面板继续使用同一连接，前台保留账号与模型状态。下次启动应用时，已启用的连接会在后台恢复，文档打开不等待它。后台不轮询，也不会自动重复发送中断的请求。主动断开、切换接入方式或退出应用时释放连接。

## 文档建议

空白对话中根据当前文档或所选文字生成最多三条调整建议，包括简短内容摘要和可直接填入输入框的修改指令。建议围绕文档的内容、结构和表达；缺少上下文时，可以建议补充相应章节，并标明待确认的信息，不直接安排实验或编造参数。生成期间只显示文字提示，正常输入不受影响。点击建议只填写指令；发送与接受修改仍由你决定。

ChatGPT 接入优先使用 [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)。没有可用的轻量模型时，保留正常输入框，不切换到更贵的模型重试。API 接入可在“文档建议模型”中填写轻量模型 ID；它与主要对话模型分别设置。

建议只在打开 Agent 面板、当前项目为空白对话时生成，不扫描其他文件或项目。每份文档的内容版本、选区、语言和模型分别缓存，最多保留 64 份结果，缓存有效期为七天。切换或重新打开相同文档可复用建议；文档修改后，可点击更新建议。普通提问会优先处理，尚未完成的建议生成会让出资源。

## 审阅、接受和撤销

如果模型的回复不完整，或修改无法在原文中定位、出现重叠，Folio 会将具体校验原因及原文反馈给模型，最多自动修正两轮。生成期间会再次核对当前草稿；原文改变时依据最新内容重新对齐。修正只生成建议，不应用修改；仍然失败时保留你的指令和对话。

修改建议先显示一张折叠卡片。点击“查看修改”，对照原文和建议；可取消勾选不需要的修改，再点击“接受修改”。接受后，修改进入当前编辑器，并按原有自动保存设置处理。

Folio 只接受能在目标范围内准确、唯一定位的修改。生成期间文档发生变化、出现外部修改待审阅、或正在编辑公式／表格时，建议不会覆盖原文。重新生成建议前，先完成当前操作。

接受后可点击“撤销修改”。如果之后又进行了其他编辑，面板会停止直接撤销，避免覆盖这些内容；此时可使用编辑器撤销或历史版本。接受前的原文也会保存为历史快照。

## 查看渲染效果

模型在需要核对排版时，可以调用只读预览工具，查看 Folio 中当前可见的写作／阅读区域。普通提问不会预先截图。预览不包含工具栏、侧栏或对话；设置弹窗、项目首页、源码视图或版本不一致时不提供画面。

画面带有文档版本与范围说明，只代表可见区域，不等于检查了整篇文档。每次请求最多查看两次，图片不保存到对话文件。模型和兼容 API 需要支持图片输入；文档建议生成不调用预览。

## 对话与上下文

对话按项目保存在本机，切换项目时分别显示。点击面板右上角的加号可开始新对话。每个项目最多保留最近 24 条消息，对话文件限制在约 3 MiB；较早消息会自动移出当前对话。

Agent 当前处理文档文本、公式和表格。回复可以排版公式；图片附件与联网检索尚未作为上下文接入。Markdown 中引用的指令视为资料；模型没有权限执行本机命令或直接写入文件。
